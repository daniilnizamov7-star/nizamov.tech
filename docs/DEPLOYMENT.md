# Размещение портфолио

## Состояние на 26.11.2026

- В Beget сайт привязан к каталогу `nizamov-tech.ru/public_html`. Редирект HTTP → HTTPS временно выключен для диагностики.
- DNS остаётся в Selectel. Авторитетный сервер Selectel вернул `91.106.207.76` для `nizamov-tech.ru` и `www.nizamov-tech.ru`. TTL по панели — 300 секунд.
- Письмо Beget подтверждает выпуск и установку сертификата для `nizamov-tech.ru`. Покрытие `www` отдельно не подтверждено. NS Beget и Selectel при прямой проверке вернули одинаковый IP `91.106.207.76` для обоих имён.
- После отключения редиректа главная, её вариант с `www` и `/privacy.html` подтверждены по HTTP с `91.106.207.76`, статус 200. HTTPS для корневого домена по-прежнему сбрасывает соединение.
- В архиве Beget обнаружено девять HTML-страниц. Восемь совпали с GitHub, `privacy.html` отличалась. Файлы при переключении не заменялись.

## Проверка и откат

Проверьте обе главные страницы по HTTPS, открытие `/privacy.html` и переход с HTTP на HTTPS. Если Beget не обслуживает домены, верните две A-записи на прежний IP `178.72.128.125`, предварительно убедившись, что там доступно портфолио. Поддомены приложений управляются отдельными DNS-записями.
